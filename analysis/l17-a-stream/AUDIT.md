## Specification, implementation and tests

The actor stores a sequence of integer run widths. The scanner critic uses
literal word substitution instead. Both are checked by raw interpreters that
consume actual bit tapes, not counter rules. Every main case compares state,
head, time, halted flag and the entire written tape;905 also compare every
read triple. Fourteen kernel templates are each checked with12 random contexts
on both sides. The main count992 includes those168 cases.

The general formulas hold under explicit guards and include all zero gaps.
Passing tests does not itself prove them. Large-parameter unit checks compare
exact lengths and clocks; those are arithmetic checks, not simulations of
huge tapes. Fifteen unit methods pass. No failed endpoint was discarded.

## Direction, types and representation attacks

C6 and D6 both move left6 cells but take6 and14 defined transitions. Spatial
shift is not time. An undefined transition performs no counted step. All head
coordinates and exterior bits are retained; removing an interior00 or changing
the token order fails the controls. A complete return endpoint is a whole
C-section, whereas the mixed boundary is an internal C head with a nonblank
left tape. These objects are not interchangeable.

## Round-trip coherence and scope decisions

The requirement was to continue from1101. The output returns an unbounded
homogeneous subfamily and exposes the mixed-width gap, rather than replacing
the original goal with a claim of global termination. The generic scanner
does handle arbitrary finite right words; its later return theorem has a
narrower homogeneous domain. The endpoint format preserves the full tape and
unread suffix. This distinction is retained in code, tests, brief and report.

No formula correction was needed in the endpoint campaign. Interpretations
explicitly withheld are universal mixed return, blank reachability, global
bounded stack, and a Lean proof. The prior handoff is recovered and checked
without editing its payloads. No current GitHub/CI status is inferred from it.
