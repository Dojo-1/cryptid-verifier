The new comparator consumes `nesting-claims.json`; it does not receive an actor
prediction as its source of truth. `verify_results.py` reconstructs the exact
requests and expectations from those schemas, checks their hashes, and compares
them against the delivered raw records. The literal comparator is the unchanged
old C++ machine interpreter, compiled afresh three ways. Separate code paths are
not independent authorship, and no new outside replication is implied.

The new symbolic verifier neither imports nor calls the orbit generator or its
word class. It reads the declarative target words and guard constraints. It
matches 73 complete checkpoints and all 443,467 retained deeper-phase claim
choices. It intentionally does not recompute the quadratic raw-time totals.

Mutation results are typed: eight mutants are caught by full literal endpoints;
four concern input guards/types. The latter are required rejections, not raw
claims about invalid parameters. The retained first harness failure occurred
before the comparator could execute any transition. A second issue found during
review affected only an unexercised short-rule bridge; regression tests now cover
all six branches. Neither defect is erased from the history.

The raw horizons and probe counts remain within the recorded budgets. Later
symbolic phases have their own recorded protocols after earlier stops. The
180-second discovery stop is not portable; the recorded endpoint has a separate
deterministic verifier. No statistical rare-event conclusion is inferred from
three tail excursions.

All 135 earlier payloads are preserved in the combined archive. The large local
verbose replay intermediate is omitted; its event-stream hash, compact complete
witnesses, sparse checkpoints, and generating code are provided. This omission
does not affect either delivered verifier. No earlier Lean or repository file is
edited by this contribution.
