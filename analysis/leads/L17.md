## Lean, machine level (`link/CryptidLink/L17.lean`)
The four branches are proved against the raw machine, for all parameters, in the upstream Turing-machine
semantics. The proof follows GPT's sweep derivation: three block sweeps by induction, plus three fixed
segments (`segAB`, `segAEF`, the ten-step `path10`). Theorems:

- `branch_b0`, `branch_a0`, `branch2`, `branch3`;
- `countdown`: C(a, 3q + r) ⊢* C(a + 5q, r) for a ≥ 1;
- `res0`, `res2`, `res1`: the collapsed countdowns from C(0, n) for n = 3k, 3k + 2, 3k + 1;
- `blank_reaches_boundary`: **from the blank tape the machine reaches C(53 262 756, 1)**.

So GPT's frontier is no longer conditional: it is a theorem about the machine, and in particular the machine
does not halt before that configuration. The Lean statements are reachability only; the raw times are from the
step-count formulas, checked numerically.

## The two-layer collapse subsystem, in Lean (`L17g.lean`; GPT derivation in [`../l17-collapse/`](../l17-collapse/COLLAPSE.md))
Write D(N, k, z) = 𝒞(0; 1^N (01)^k 1^(3z) T) for N ≥ 2 and k, z ≥ 1, and let N = 3q + r. Each decision is entry plus
countdown, followed by:

- `D_r0`: r = 0 absorbs the k pairs, giving S(1+5q+k, 3z, 7, 3);
- `D_r1`: r = 1 applies F111, giving D(10q−6, k+7, z−1). `D_r1z` covers z = 1, which gives S(0, 10q−6, k+14, 3);
- `D_r2`: r = 2 applies P then Z, giving D(10q+15, k−1, z). `D_r2k` covers k = 1, which gives S(0, 10q+15+3z, 7, 3).

The rank k + 8z drops by exactly one at every non-return decision. `D_returns` is the induction on that rank:
**every D state reaches a one-tail state S**.

`push_returns` combines this with F1100: **S(u+7, 1, 3j+8, 1) ⊢⁺ some S** for all u and j. In other words, every push
whose tail width c ≡ 2 (mod 3) collapses back to one layer. The case a ≡ 0 (mod 3) is `LF1100R`. Each row lemma is
just entry/countdown, F111, P and Z composed with tape equalities. No new kernel is needed.

GPT ran its continuation for 2,000,000 rewrites. It saw seven pushes and never a third layer. The push guard
(a ≡ 0 or c ≡ 2 mod 3) does not survive arbitrary S states: S(9,1,8,4) → S(16,1,15,1) breaks it. So bounded stack
depth on the blank orbit is still open. Package checks: integrity (53 files), its 12 tests, and `verify_raw.py`
were all re-run here.

## General D/G rows, JOIN and RET729, in Lean (`L17h.lean`, `L17i.lean`)
With an arbitrary right context V, D(N,k,m;V) = 𝒞(0; 1^N (01)^k 1^m V) and G(N,k;V) = 𝒞(0; 1^N (01)^k 0 V):

- `Dg0`, `Dg1`, `Dg12`, `Dg2` and `Dg2k`, plus `Gg0`, `Gg1`, `Gg2` and `Gg2k`. These are GPT's rows for every middle m.
  D12 keeps the interior zero, and G1 removes one pair from the terminal. Each row composes `stepEC` with one of F111,
  F100, P/Z, P or Z, plus tape equalities.
- `JOIN`: 𝒞(u+7; (10)^(e+5) 11 (01)^(j+1) 11 v) ⊢⁺ 𝒞(0; 1^(2u+2) (01)^7 1^(2e+1) (01)^(j+7) 0 v). It is built only
  from existing kernels: entry, A sweep, K11, A sweep, K7, A sweep, `segAEF`, D sweep, K22, C sweep, K43, C sweep.
  `Dg11J` is D(3p+7, e+5, 1; (01)^(j+1) 1^(s+3) W) ⊢⁺ D(10p+10, 7, 2e+1; (01)^(j+8) 1^s W).
- `RET729`: **S(729t+548, 1, g+11, 1) ⊢⁺ S(10⁶t+740902, 2g, 7, 3)** for all t and g. It is F1100 followed by
  D1, D1, D1, D2, D2, D0, and it covers the width-39 push (g = 28).

`L17j.lean` formalizes GPT's opposite-stream results for the internal D/G graph. `IStep` is made of the six guarded
rows D1, D2, D12, G1, G2 and D11join.

- `IStep.sound`: every edge is a machine-reachability step.
- `internal_step_injective`: every state has at most one predecessor.
- `internal_step_decreases_lex`: the rank (s, l, R) decreases along every edge, with R = 3k+8m+3 on D and 3k on G.
- `internal_predecessor_decreases_lex`: (N, k) increases along every edge, so every ancestry is finite.
- `push_entry_is_root`: no edge leads into an F1100 output.
- `internal_terminates`: from every state the machine reaches a state with no internal successor.

`L17k.lean` adds symmetry and antisymmetry results:

- `internal_acyclic`, `internal_step_irrefl` and `internal_step_asymm`: there are no internal cycles of any length,
  because every nonempty path decreases the rank.
- `internal_unique_root`: two roots that reach the same state are equal. With `push_entry_is_root`, this gives
  `push_entries_disjoint`: distinct F1100 entries have disjoint internal descendants.
- `raw_not_injective`: the raw machine is not reversible. This is GPT's witness, where A at −1 and C at +1 both
  step to B at 0. Backward uniqueness therefore comes from the macro domain, not from the machine.
- `no_affine_rank`: no per-mode score affine in (k, m, l, s) decreases on every internal edge. The proof uses GPT's
  D1/D2/D12/G1 inequalities, which force 11·aD < 0 while D2 forces aD > 0.

Every lemma depends only on the standard axioms. Universal collapse and a bound on stack depth remain **open**.
GPT's opposite-stream package [`../l17-frames/`](../l17-frames/CLAUDE-BRIEF.md) is integrated; its 18 tests pass here.
It shows that internal predecessors are unique, that F1100 entries are roots, and it gives a lexicographic rank
(s, l, R). It also has small F1100 inputs that end at uncovered JOIN guards: a = 37 stops at width 4, and a = 46
reaches s = 0. My contextual stepper stops at both of them as well. Neither input is claimed to lie on the blank
orbit.

### Composing interleaved return blocks

Write `Q = 10` and `X = 010` in head-nearest-first order on the left
of C. The new bridge consumes `X Q^3 X` in 34 steps. It changes the
right guard `111 R` into `111 011010101010 R`, moving the head twelve
cells left, without reading either exterior tape.

| Left block | Return clock | Right output after the restored `111` |
| --- | ---: | --- |
| `Q` | 2 | `11 R` |
| `XX` | 6 | `010111 R` |
| `X Q^3 X` | 34 | `011010101010 R` |
| `X Q^(j+5)` | `43 + 2j` | `scannerWideSuffix j R` |

Every row restores the same three-one guard. Therefore

## Why a ≢ 0 (mod 3) is harder
For a ≡ 1 or 2 (mod 3), first returns from C(a,1) look irregular: 23 to more than 3·10⁶ steps, with targets
such as C(13,0), C(8,31), C(55,0), C(888,0). The intermediate tapes show why. The b = 1 branch leaves a
**second block pair** behind:

    C(11,1) ⇝ C> 0 1^11 (01)^7 1^3 ⇝ C> (01)^6 1^7 (01)^7 1^3 ⇝ … ⇝ C> (01)^36 1^3 (01)^14 ⇝ C(55,0)

The countdown (a, b) → (a+5, b−3) runs unchanged with an inert tail (01)^c 1^d to its right. So the natural
section is a word in blocks, C> (01)^a₁ 1^b₁ (01)^a₂ 1^b₂ …, with the head working on the leftmost pair. This
is stack-like, not a fixed number of counters. The next step is to derive the rules on that stack section.
