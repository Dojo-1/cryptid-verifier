# L17 = `1RB0RE_1LC0RA_0LD1LB_1LA1LE_0LB0LF_1LD---` (exploratory, not a proof)

Section: C(a,b) = 0^∞ C> (01)^a 1^b 0^∞. GPT's report (`gpt-2026-10-20/report.md`) gives four branches and
an open boundary at b = 1. Its ZIP was not received here; everything below was re-derived independently.

## Independent re-check of GPT's branches
`l17_check.py` runs the raw machine from each full configuration to its **first** exact return to the section:

| Guard | Target | Raw steps | Head shift |
|---|---|---|---|
| b = 0 | C(0, 2a+4) | 4a+8 | −2 |
| a = 0, b ≥ 1 | C(1, b) | 2 | −2 |
| a ≥ 1, b = 2 | C(a+4, 0) | 6a+21 | −7 |
| a ≥ 1, b ≥ 3 | C(a+5, b−3) | 6a+21 | −7 |

3 541 grid cases (0 ≤ a, b < 60) agree, including step counts, so these are first returns. Using these rules,
the blank orbit reproduces GPT's numbers exactly: C(0,b) for b = 14, 54, 186, …, 31 957 654, then the open
boundary C(53 262 756, 1) at raw time 1 870 497 627 040 360.

## Lean, machine level (`link/CryptidLink/L17.lean`)
The four branches are proved against the raw machine, for all parameters, in the upstream Turing-machine
semantics. The proof follows GPT's sweep derivation: three block sweeps by induction, plus three fixed
segments (`segAB`, `segAEF`, the ten-step `path10`). Theorems:

- `branch_b0`, `branch_a0`, `branch2`, `branch3`;
- `countdown`: C(a, 3q + r) ⊢* C(a + 5q, r) for a ≥ 1;
- `res0`, `res2`, `res1`: the collapsed countdowns from C(0, n) for n = 3k, 3k + 2, 3k + 1;
- `blank_reaches_boundary`: **from the blank tape the machine reaches C(53 262 756, 1)**.

So GPT's frontier is no longer conditional: it is a theorem about the machine, and in particular the machine
does not halt before that configuration. The Lean statements are reachability only; the raw times are from the
step-count formulas, checked numerically.

## The b = 1 branch for a ≥ 7, and C(3k, 1), in Lean (`link/CryptidLink/L17b.lean`)
With T = (01)^7 1^3 and C(a, b)·X = 0^∞ C> (01)^a 1^b X:

- `R1`: **C(a, 1) ⊢⁺ C(0, 2a − 12)·T** for a ≥ 7. In raw steps this is 4a + 50 with head shift −2, checked for
  7 ≤ a < 300. Structure: entry, A sweep over a + 1 pairs, a fixed 60-step segment that reads only the last 8 pairs
  plus 2 cells (`segR1`), then a C sweep back over a − 7 pairs.
- The countdown rules hold with any tail (`branch3T`, `countdownT`), and C(x, 0)·T is literally C(x + 7, 3).
- `C3k`: **C(3k, 1) ⊢⁺ C(10k − 12, 3)** for k ≥ 3. This proves the rule that had only been fitted numerically.
- `blank_reaches_boundary2`: **from the blank tape the machine reaches C(6 575 648 756, 1)** (≈ 2.85·10¹⁹ raw
  steps by the step formulas). Here a ≡ 2 (mod 3), the first case not yet handled.

## The other residues and the contextual calculus (GPT derivation, Lean in `link/CryptidLink/L17c.lean`)
GPT's derivation is in [`../l17-stacked-section/DERIVATION.md`](../l17-stacked-section/DERIVATION.md). It covers
both nonzero residues, three context-preserving lemmas and a stack-producing rule. Write 𝒞(a; X) =
0^∞ C> (01)^a X with arbitrary right context X. Proved against the raw machine:

- `zT`: 𝒞(a; 00w) ⊢⁺ 𝒞(0; 1^(2a+4) w), and `pzT`: 𝒞(a+1; 11 (01)^(m+1) X) ⊢⁺ 𝒞(0; 1^(2a+15) (01)^m X);
- `F100`: 𝒞(u+7; (10)^(c+1) 0 v) ⊢⁺ 𝒞(0; 1^(2u+2) (01)^7 1^(2c+3) v);
- `F111`: 𝒞(u+5; (10)^(d+1) 111 v) ⊢⁺ 𝒞(0; 1^(2u+2) (01)^(d+7) 0 v);
- the fixed kernels K11, K43 and K22 run on symbolic outside context, so leaving the context untouched is part
  of the proof, not an assumption;
- `blank_reaches_boundary3`: **from the blank tape the machine reaches C(30 066 981 019 881, 27)**. It passes the
  a ≡ 2 (mod 3) boundary and returns to the plain two-counter section. The 14-step chain matches GPT's derived
  trace checkpoint for checkpoint.

GPT also found that the single-tail shape is not closed: C(7,1)·(01)^8 1 ⊢ C(0,2)·T·T in 152 steps (checked
independently here). GPT's 2,000-rewrite symbolic extension never needed a second layer. Whether the blank orbit
ever does, or ever reaches a halt, is open.

## The orbit to the end of GPT's 2,000-rewrite trace, in Lean (`L17d.lean`, `L17Orbit0..5.lean`)
Every state in GPT's trace has at most one tail. It can be written S(a, b, k, s) = 0^∞ C> (01)^a 1^b (01)^k 1^s
0^∞. `L17d.lean` turns the proved lemmas into nine macro moves on S with explicit arithmetic side conditions:
entry+countdown, countdown, P→Z, plain P+Z, plain Z, R1, F100, F111, and the merges. An independent stepper,
`l17_orbit2.py`, follows the orbit in this state space. `l17_gen_orbit.py` emits one small theorem per macro
step, and every side condition is a `norm_num` goal.

- **`Orbit.blank_reaches_trace_end`: from the blank tape the machine reaches S(a, 2, 7, 3) with
  a ≈ 2.04·10^295** (981 bits). That is exactly the endpoint of GPT's 2,000-rewrite trace, reached in 1,251
  macro steps. The six files build in about 30 s.
- The stepper ran 30,000 macro steps past C(30066981019881, 27) without needing F1100 or any other unformalized
  case. The tail stayed within (01)^54 1^31. This is evidence that the blank orbit keeps a single tail, but it is
  not a proof.

## Stack-producing rules, in Lean (`L17e.lean`; GPT derivation in [`../l17-stack/`](../l17-stack/NESTING.md))
With T = (01)^7 1^3 and U = (01)^8 1:

- `F1100`: 𝒞(u+7; (10)^(d+7) 1100 v) ⊢⁺ 𝒞(0; 1^(2u+2) (01)^7 1^(2d+1) T v), with arbitrary context.
- `nestA`: (10)^8 A> 1 U^n 00 ⊢⁺ C> 11 T^(n+1). This is the induction on n, with arbitrary context on both
  sides. It uses the new kernels K7 and K41 and the contextual K60.
- `nest`: 𝒞(u+7; 1 U^n 00 v) ⊢⁺ 𝒞(0; 1^(2u+2) T^(n+1) v). This is a uniform layer push for every n.
- `stack_two`: C(7,1)·(01)^8 1 ⊢⁺ C(0,2)·T·T, and `stack_three`: C(7,1)·U² ⊢⁺ C(0,2)·T³.

On the blank orbit, GPT's continuation (673,467 rewrites) finds three two-layer excursions, and each collapses back
to one layer. The first is F1100 at C(A,1)·(01)^76 1, with A of 107,633 bits and A ≡ 0 (mod 3). Here, the
independent one-tail stepper `l17_orbit2.py` stops at exactly that state after 143,228 macro steps, with the same A.
That is two engines agreeing on where the first stack push happens. Whether the stack depth on the blank orbit
stays bounded is still open.

## Hardening (GPT, [`../l17-hardening/`](../l17-hardening/AUDIT.md))
These are bounded checks by separate code paths, not proofs:

- A separate C++ literal-machine comparator agrees on all 6,381 rule endpoints.
- 16 kernel read windows were tested against arbitrary two-sided contexts.
- ACAF planted 20 source mutations; all were detected.
- ACAF also found and fixed a real bug in the new comparator. No L17 formula changed.
- GPT's full campaign was replayed from scratch here (fresh O2/O0/UBSan builds, no cached outputs) with the same
  result: 6,381/6,381 endpoints, 192/192 windows, 20/20 mutants.
- The 18 rule seeds in `regression-seeds.json` were re-run here through a fourth independent simulator, and all
  agree.
- The Lean theorems above don't depend on any of this: they are proved against the upstream machine semantics.

## The b = 1 branch when a ≡ 0 (mod 3): the original numerical fit

    C(3k, 1) → C(10k − 12, 3)   in 60k² − 204k + 244 raw steps, head shift 24 − 14k   (k ≥ 2)

This was checked exactly for k = 2…69 and k = 100, 150, 211, 300. It is not derived.

## Why a ≢ 0 (mod 3) is harder
For a ≡ 1 or 2 (mod 3), first returns from C(a,1) look irregular: 23 to more than 3·10⁶ steps, with targets
such as C(13,0), C(8,31), C(55,0), C(888,0). The intermediate tapes show why. The b = 1 branch leaves a
**second block pair** behind:

    C(11,1) ⇝ C> 0 1^11 (01)^7 1^3 ⇝ C> (01)^6 1^7 (01)^7 1^3 ⇝ … ⇝ C> (01)^36 1^3 (01)^14 ⇝ C(55,0)

The countdown (a, b) → (a+5, b−3) runs unchanged with an inert tail (01)^c 1^d to its right. So the natural
section is a word in blocks, C> (01)^a₁ 1^b₁ (01)^a₂ 1^b₂ …, with the head working on the leftmost pair. This
is stack-like, not a fixed number of counters. The next step is to derive the rules on that stack section.
